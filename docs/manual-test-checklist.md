# Manual Test Checklist

## 启动和数据

- [ ] 首次启动自动创建 `vault.json`。
- [ ] 首次启动自动创建 `settings.json`。
- [ ] `vault.json` 使用 `schema: 2` 和 `app: local-server-vault`。
- [ ] 损坏 `vault.json` 后重启，会保留损坏副本并尝试从备份恢复。

## 服务器管理

- [ ] 可以新增服务器。
- [ ] 名称为空会被拒绝。
- [ ] IP/地址为空会被拒绝。
- [ ] 端口小于 1 或大于 65535 会被拒绝。
- [ ] 可以保存登录名。
- [ ] 可以保存密码。
- [ ] 可以保存分组、标签、备注。
- [ ] 编辑服务器后 revision 增加。
- [ ] 删除服务器前会确认。
- [ ] 删除服务器前会自动备份。

## UI

- [ ] 左侧显示 All Hosts、Groups、Tags。
- [ ] 中间以卡片网格展示服务器。
- [ ] 右侧显示服务器详情。
- [ ] 详情页密码默认隐藏。
- [ ] 设置中打开“显示密码明文”后，详情页显示密码。

## 搜索过滤

- [ ] 搜索服务器名称能匹配。
- [ ] 搜索 IP/域名能匹配。
- [ ] 搜索登录名能匹配。
- [ ] 搜索密码能匹配。
- [ ] 搜索分组、标签、备注能匹配。
- [ ] 点击分组能过滤。
- [ ] 点击标签能过滤。
- [ ] 点击 All Hosts 清除过滤。

## 复制

- [ ] 可以复制地址。
- [ ] 可以复制登录名。
- [ ] 可以复制密码。

## SSH

- [ ] 详情页显示 SSH 按钮。
- [ ] 点击 SSH 按钮会调用本机终端。
- [ ] SSH 命令包含正确的 IP/地址、端口和登录名。
- [ ] 登录名为空时，SSH 命令只使用地址。
- [ ] 密码不会拼进 SSH 命令。
- [ ] 地址或登录名含危险字符时，阻止启动并提示错误。

## JSON 导出

- [ ] 点击导出前会提示 JSON 包含密码。
- [ ] 导出文件名为 `server-vault-YYYYMMDD-HHmmss.json`。
- [ ] 导出 JSON 包含服务器密码。
- [ ] 导出 JSON 不包含 settings。
- [ ] 导出 JSON 不包含 backups。

## JSON 导入

- [ ] 点击导入可以选择 JSON 文件。
- [ ] 导入前自动备份当前 `vault.json`。
- [ ] 导入前出现覆盖确认。
- [ ] 合法 JSON 导入成功。
- [ ] 非法 JSON 被拒绝。
- [ ] schema 不匹配被拒绝。
- [ ] 导入后 revision 为当前本地 revision + 1。

## 构建

- [ ] `npm run build` 通过。
- [ ] `cargo fmt --check` 通过。
- [ ] `cargo clippy -- -D warnings` 通过。
- [ ] `npm run tauri:build` 通过。
